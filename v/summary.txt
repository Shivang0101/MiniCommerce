[VERSION 1: FOUNDATION & API ARCHITECTURE]
- Fast, asynchronous Python 3.12 FastAPI backend + SQLAlchemy ORM.
- 4-Tier initial layering (Routers, Services, Repositories, Models).
- Basic PostgreSQL connection pooling + Vanilla HTML frontend storefront.

[VERSION 2: DATABASE ENGINEERING & HIGH-CONCURRENCY LABORATORY]
- 5-Tier Data Layer strictly separating Router, Service, Repository, and Model tiers.
- B-Tree Indexing Optimization (`ix_users_email` reducing user email lookup latency by ~80x: 4.148ms ➔ 0.052ms).
- Pessimistic Row-Level Locking (`SELECT FOR UPDATE` + deterministic ID sorting preventing deadlocks under concurrent checkout).
- Composite unique constraint idempotency engine.
- 409,913 record benchmark dataset on Supabase PostgreSQL AWS Cloud.

[VERSION 3: CONTAINERIZATION, DISTRIBUTED CACHING & RESILIENT STATE]
- Production Docker Compose topology (FastAPI Backend, Redis 7 Alpine, Nginx SPA).
- Async Redis Cache-Aside Pattern (~36x catalog read latency speedup: 102.4ms ➔ 2.8ms).
- Write invalidation engine (purging catalog cache keys on stock mutations).
- Resilient DB Fallback (0.2s failover: 0% HTTP 500 error impact when Redis goes down).

[VERSION 4: ASYNC TASK QUEUE, RATE LIMITING & ADMIN OBSERVABILITY]
- ARQ Redis Background Worker Pool (decoupled receipt emails, inventory auditing, analytics).
- Redis ZSET Sliding-Window Rate Limiter Middleware (`RateLimiterMiddleware`).
- Admin Observability Panel UI (`/admin`) protected by `is_admin` claim.

[VERSION 5: ENTERPRISE SECURITY, DISTRIBUTED RESILIENCE & DATA ENGINEERING]

- Scoped Role-Based Access Control (RBAC) (`CUSTOMER`, `STORE_MANAGER`, `SRE_ADMIN`).
- Thread-Safe Circuit Breaker State Machine (`CLOSED` ➔ `OPEN` ➔ `HALF-OPEN`).
- Transactional Outbox Pattern Engine (guaranteeing 100% side-effect message durability).
- Health Probe Separation (`/healthz/liveness` and `/healthz/readiness`).
- Keyset Cursor Pagination (`GET /products/keyset` achieving `O(1)` constant latency avoiding deep OFFSET scans).
- Soft Deletion & SHA-256 Payload-Hashed Idempotency Engine.
- React Store Manager Portal UI & Axios 401 automatic token refresh interceptor.
