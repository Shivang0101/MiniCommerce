On Windows PowerShell, fix the SSH .pem key permission so Windows SSH client doesn't block connection:

```powershell

icacls mini-commerce-key.pem /grant:r "$($env:USERNAME):(R)"
```

4. EC2 INITIAL SYSTEM SETUP & DOCKER INSTALLATION
--------------------------------------------------------------------------------
Once connected inside the EC2 terminal (`ubuntu@ip-...`):

```bash
# Update Ubuntu system packages
sudo apt-get update && sudo apt-get upgrade -y

# Install Docker and Docker Compose plugin
sudo apt-get install -y docker.io docker-compose-v2 git

# Enable Docker daemon service
sudo systemctl enable --now docker

# Add ubuntu user to docker group to run docker without sudo
sudo usermod -aG docker ubuntu

# Exit and reconnect SSH so group changes take effect
exit
```

Re-connect via SSH:
```powershell
ssh -i "D:\shivang\Project\aws_workspace\credentials\mini-commerce-key.pem" ubuntu@<YOUR-EC2-PUBLIC-IP>
```

7. PRODUCTION PORT BINDING FIX (3000:80 -> 80:80)
--------------------------------------------------------------------------------
By default, docker-compose.yml maps frontend to host port 3000 (`3000:80`).
For direct HTTP access via browser on standard Port 80 (`http://<EC2-PUBLIC-IP>`), run:

```bash
sed -i 's/"3000:80"/"80:80"/g' docker-compose.yml
```

11. PAUSING (STOPPING) & RESUMING (RESTARTING) EC2 TO SAVE MONEY
--------------------------------------------------------------------------------

### A. How to Pause (Stop Instance):
1. Go to AWS Console -> EC2 -> Instances.
2. Select your instance (`i-08e8f26d2e6dda03a`).
3. Click "Instance state" dropdown -> Click "Stop instance" (Do NOT click Terminate).
* Result: CPU/RAM compute billing stops immediately ($0 compute cost). All your code, Docker containers, images, and secrets remain 100% saved on your disk.

---

### B. How to Resume (Start Instance Again):
1. Go to AWS Console -> EC2 -> Instances.
2. Select your instance -> Click "Instance state" -> Click "Start instance".
3. Wait 30 seconds until Instance State shows "Running".
4. Copy the NEW Public IPv4 Address (AWS assigns a new IP upon restart).

---

### C. What to do after Starting:
* You DO NOT need to run docker commands again! Docker automatically restarts all 4 containers within 15 seconds because `docker-compose.yml` has `restart: always`.
* Open your browser and go to your new IP:
  ```text
  http://<NEW-EC2-PUBLIC-IP>
  ```
* To SSH into EC2 again from PowerShell, use the new IP:
  ```powershell
  ssh -i "D:\shivang\Project\aws_workspace\credentials\mini-commerce-key.pem" ubuntu@<NEW-EC2-PUBLIC-IP>
  ```

🗄️ 1. Database & In-Memory Caching (Replacing Supabase & Docker Redis)
AWS RDS for PostgreSQL: Managed PostgreSQL database with automated backups, point-in-time recovery, and auto-scaling (replaces Supabase).
AWS ElastiCache for Redis: Managed, high-availability Redis cluster for catalog caching, rate limiting, and ARQ queueing (replaces local Docker Redis).
🐳 2. Serverless Containers (Modern alternative to managing EC2 servers)
AWS ECR (Elastic Container Registry): Private Docker registry to store and version your Docker images.
AWS ECS (Elastic Container Service) + Fargate: Serverless container runner. Runs your FastAPI, Worker, and Nginx containers without requiring you to manage EC2 OS updates or SSH.
🌐 3. Networking, Domains & SSL Security
AWS Route 53: DNS domain management (connects your custom domain like my-store.com to AWS).
AWS ALB (Application Load Balancer): Automatically routes web traffic to containers and handles traffic surges.
AWS ACM (Certificate Manager): Free SSL certificates for https:// support.
AWS VPC (Virtual Private Cloud): Places your database & Redis in private subnets so hackers cannot touch them from the public internet.
🪣 4. Media Storage & Global CDN
AWS S3 (Simple Storage Service): Cloud bucket storage for product images, user uploads, and invoice PDFs.
AWS CloudFront: Global Content Delivery Network (CDN) to serve your React frontend assets at lightning speed worldwide.
📊 5. Secrets & Monitoring
AWS Secrets Manager: Securely holds production environment secrets (JWT_SECRET, DB passwords).
AWS CloudWatch: Centralized log viewer and CPU/Memory alert monitor for all containers.
