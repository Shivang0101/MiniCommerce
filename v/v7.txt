2. Dynamic AWS Secrets Manager Resolver (`backend/app/core/cloud_secrets.py`):
```python
def get_secret(secret_name: str, region_name: str = "us-east-1") -> str | None:
    env = os.getenv("ENVIRONMENT", "development").lower()
    if env not in ("staging", "prod", "production"):
        return None
    try:
        import boto3
        client = boto3.client("secretsmanager", region_name=region_name)
        response = client.get_secret_value(SecretId=secret_name)
        if "SecretString" in response:
            return response["SecretString"]
    except Exception as e:
        logger.warning(f"Unable to fetch AWS secret '{secret_name}': {e}")
    return None
```

[SECTION 5: COMPLETE TROUBLESHOOTING LOG & RESOLUTIONS (ALL 7 ISSUES)]
================================================================================

1. Error: `FreeTierRestrictionError` / `InvalidParameterCombination`
   - Symptom: Backup retention period (>1 day) or unsupported exact engine version (`15.3`) failed creation.
   - Root Cause: AWS RDS Free Tier restricts retention period to 1 day.
   - Solution: Set `backup_retention_period = 1`, `performance_insights_enabled = false`, and `engine_version = "15"` in `terraform/modules/rds/main.tf`.

2. Error: `CannotPullContainerError`
   - Symptom: ECS task stuck in `STOPPED` state with `failed to resolve ref ghcr.io...`.
   - Root Cause: Fargate tasks in private subnets without public egress cannot reach `ghcr.io`.
   - Solution: Attached ECS tasks to public subnets (`public_subnet_ids`) and enabled `assign_public_ip = true` in `terraform/modules/ecs/main.tf`.

3. Error: `401 Unauthorized` on container pull
   - Symptom: Fargate tasks fail image pull despite public IP assignment.
   - Root Cause: GitHub Container Registry (GHCR) sets new container packages to Private by default.
   - Solution: Changed visibility of `minicommerce-backend`, `minicommerce-worker`, and `minicommerce-frontend` packages to **Public** in GitHub Package Settings.

4. Error: `sqlalchemy.exc.OperationalError: (sqlite3.OperationalError) near "EXISTS": syntax error` -> `504`
   - Symptom: Backend container crashed on startup causing 504 Gateway Timeout.
   - Root Cause: `ALTER TABLE ... IF NOT EXISTS` is valid in PostgreSQL 15 but crashes SQLite test environments.
   - Solution: Gated migrations inside `if engine.dialect.name == "postgresql":` and wrapped in try/except blocks in `backend/app/main.py`.

5. Error: `Failed to initialize Redis pool on startup: Timeout reading from master.minicommerce-staging-redis...`
   - Symptom: Redis connection timeout on startup.
   - Root Cause: `backend/app/core/redis.py` hardcoded `socket_connect_timeout=0.5` (500ms). Network connections across AWS subnets took ~0.8s, causing socket timeouts. Additionally, ElastiCache TLS requires `rediss://`.
   - Solution: Increased `socket_connect_timeout=3.0` in `redis.py` and set `REDIS_URL = "rediss://..."` scheme in `terraform/modules/ecs/main.tf`.

6. Error: `InvalidParameterCombination: Modification of transit encryption is not supported`
   - Symptom: `terraform apply` failed when modifying replication group.
   - Root Cause: AWS ElastiCache API forbids toggling transit encryption live on an existing cluster with AUTH token without recreation.
   - Solution: Added `apply_immediately = true` and retained `transit_encryption_enabled = true` in `terraform/modules/elasticache/main.tf`.

7. Error: `[emerg] host not found in upstream "backend" in default.conf:13` -> `503`
   - Symptom: Root URL `http://minicommerce-staging-alb.../` returned 503.
   - Root Cause: `frontend/nginx.conf` contained local Docker-Compose `proxy_pass http://backend:8000/api/`. On AWS, ALB handles path routing (`/api/*` -> backend, `/*` -> frontend). Nginx crashed looking for Docker host `backend:8000`.
   - Solution: Removed Docker-only `proxy_pass` blocks from `frontend/nginx.conf` so Nginx focuses strictly on React SPA static delivery (`/usr/share/nginx/html`).
