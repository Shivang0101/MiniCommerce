2. Dynamic AWS Secrets Manager Resolver (`backend/app/core/cloud_secrets.py`):
```python
def get_secret(secret_name: str, region_name: str = "us-east-1") -> str | None:
    env = os.getenv("ENVIRONMENT", "development").lower()
    if env not in ("staging", "prod", "production"):
        return None
    try:
        import boto3
        client = boto3.client("secretsmanager", region_name=region_name)
        response = client.get_secret_value(SecretId=secret_name)
        if "SecretString" in response:
            return response["SecretString"]
    except Exception as e:
        logger.warning(f"Unable to fetch AWS secret '{secret_name}': {e}")
    return None
```

3. VPC Multi-AZ Network Module (`terraform/modules/vpc/main.tf`):
```hcl
resource "aws_vpc" "main" {

  count                   = length(var.public_subnet_cidrs)
  vpc_id                  = aws_vpc.main.id
  cidr_block              = var.public_subnet_cidrs[count.index]
  availability_zone       = var.availability_zones[count.index]
  map_public_ip_on_launch = true
}
```

1. Error: `ModuleNotFoundError: No module named 'arq'`
   Symptom: `python -m pytest tests` failed when run with system Python.
   Root Cause: System python interpreter lacked local virtual environment packages.
   Solution: Invoked pytest using virtual environment binary: `.\.venv\Scripts\python.exe -m pytest tests`.

   Symptom: `terraform plan` failed with `failed to refresh cached credentials` error.

[SECTION 7: COMPLETE STEP-BY-STEP EXECUTION & SETUP GUIDE]
================================================================================

STEP 1: INSTALL TOOL PREREQUISITES (PowerShell):
   winget install HashiCorp.Terraform
   winget install Amazon.AWSCLI

STEP 2: GENERATE AWS ACCESS KEYS (AWS Web Console):
   1. Log into AWS Console (https://aws.amazon.com) -> Go to IAM service.
   2. Select Users -> Create User (e.g. `developer-cli`) -> Attach `AdministratorAccess` policy.
   3. Go to Security Credentials tab -> Create Access Key -> Select CLI.
   4. Copy Access Key ID (AKIA...) and Secret Access Key.

STEP 3: CONFIGURE AWS CLI (PowerShell):
   aws configure
   - AWS Access Key ID: <paste AKIA...>
   - AWS Secret Access Key: <paste secret key>
   - Default region name: us-east-1
   - Default output format: json

STEP 4: LOCAL TERRAFORM INITIALIZATION & VALIDATION (0 AWS Cost):
   cd terraform/environments/staging
   terraform init -backend=false
   terraform validate

STEP 5: DRY-RUN EXECUTION PLAN (0 AWS Cost, Read-Only):
   cd terraform/environments/staging
   terraform plan

STEP 6: APPLY LIVE AWS DEPLOYMENT (Optional):
   cd terraform/environments/staging
   terraform apply

STEP 7: DESTROY AWS DEPLOYMENT (Clean Teardown):
   cd terraform/environments/staging
   terraform destroy

STEP 8: BACKEND UNIT TEST SUITE:
   cd backend
   .\.venv\Scripts\python.exe -m pytest tests
