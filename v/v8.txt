1. Prometheus Metrics Exporter Engine (`backend/app/core/telemetry.py`):
```python
from prometheus_client import Counter, Gauge, Histogram
from prometheus_fastapi_instrumentator import Instrumentator

HTTP_REQUESTS_TOTAL = Counter(
    "minicommerce_http_requests_total",
    "Total HTTP requests received",
    ["method", "handler", "status"],
)

REDIS_CACHE_HITS = Counter(
    "minicommerce_redis_cache_hits_total",
    "Total Redis cache hits",
)

CIRCUIT_BREAKER_STATE = Gauge(
    "minicommerce_circuit_breaker_state",
    "Circuit breaker state (0=CLOSED, 1=HALF-OPEN, 2=OPEN)",
    ["name"],
)

def setup_telemetry(app: FastAPI) -> Instrumentator:
    instrumentator = Instrumentator(
        should_group_status_codes=False,
        should_ignore_untemplated=True,
    )
    instrumentator.instrument(app).expose(app, endpoint="/metrics", tags=["telemetry"])
    return instrumentator
```

2. Amazon Managed Prometheus (AMP) & Grafana (AMG) IaC Module (`terraform/modules/observability/main.tf`):
```hcl
resource "aws_prometheus_workspace" "main" {
  alias = var.workspace_alias
}

resource "aws_grafana_workspace" "main" {
  name                     = var.grafana_name
  account_access_type      = "CURRENT_ACCOUNT"
  authentication_providers = ["AWS_SSO"]
  permission_type          = "SERVICE_MANAGED"
}

resource "aws_iam_policy" "amp_ingest" {
  name        = "minicommerce-${var.environment}-amp-ingest-policy"
  description = "Allows ECS Fargate containers to remote write metrics to Amazon Managed Prometheus (AMP)"

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect   = "Allow"
        Action   = ["aps:RemoteWrite", "aps:GetSeries", "aps:GetLabels", "aps:GetMetricMetadata"]
        Resource = "${aws_prometheus_workspace.main.arn}"
      }
    ]
  })
}
```

   - Symptom: Pytest initialization failed on `setup_telemetry(app)` call in `main.py`.
   - Root Cause: `prometheus-fastapi-instrumentator` v8.1.0 changed `__init__` constructor parameter names.
   - Solution: Refactored `Instrumentator` initialization in `backend/app/core/telemetry.py` to use standard positional/keyword arguments (`should_group_status_codes=False, should_ignore_untemplated=True`).
