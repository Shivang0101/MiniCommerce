[STEP 6: DETAILED ERROR LOG & RESOLUTION TRACKER]
- Error: ModuleNotFoundError: No module named 'passlib'
  * Solution: Installed passlib[bcrypt] and bcrypt into .venv.

- Error: ImportError: email-validator is not installed, run pip install pydantic[email]
  * Solution: Added email-validator>=2.1.0 to requirements.txt for Pydantic EmailStr validation.

- Error: ValueError: password cannot be longer than 72 bytes (Passlib 1.7.4 / Bcrypt 5.0 compatibility bug)
  * Solution: Replaced passlib CryptContext with direct bcrypt routines (bcrypt.hashpw and bcrypt.checkpw) in app/core/security.py.

- Error: InvalidRequestError: When initializing mapper Mapper[User(users)], expression 'Cart' failed to locate a name ('Cart')
  * Solution: Updated app/db/seed.py to import Base, User, Product, Cart, CartItem, Order, OrderItem from app.db.base.

- Error: MissingGreenlet: greenlet_spawn has not been called when accessing relationship attributes during checkout
  * Solution: Eagerly loaded relationships using selectinload(Cart.cart_items).selectinload(CartItem.product) with populate_existing=True.

- Error: Browser ERR_ADDRESS_INVALID on IPv6 host notation [::]:3000
  * Solution: Added --bind 127.0.0.1 flag to python -m http.server command.

- Error: socket.gaierror: [Errno 11003] getaddrinfo failed on direct Supabase hostname db.[ref].supabase.co
  * Solution: Configured IPv4-supported connection pooler hostname aws-0-ap-south-1.pooler.supabase.com:6543.

- Error: Password URL parsing error due to raw '@' in password MiniCommerceDB@123@123@123
  * Solution: URL-encoded '@' to '%40' in DATABASE_URL.

- Error: asyncpg.exceptions.DuplicatePreparedStatementError on PgBouncer startup
  * Solution: Added statement_cache_size=0 and prepared_statement_cache_size=0 to connect_args in app/db/session.py.

- Error: Uvicorn infinite reload loop scanning .venv
  * Solution: Added --reload-exclude ".venv" flag to uvicorn command line.
